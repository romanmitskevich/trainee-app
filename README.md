# Новички: первые 90 дней

Инструмент для руководителей и HR. Показывает, с кем из новичков пора поговорить (3-й, 14-й, 30-й, 60-й, 80-й день работы), хранит итог разговора и собирает сводку: где, когда и почему новички уходят в первые 90 дней.

Это прототип для тестового задания: всё хранится в localStorage браузера, общего хранилища для руководителей и HR нет.

Данные берутся из задач Битрикс24 «Приём сотрудника: …» и «Увольнение сотрудника: …». Формат описан на вкладке «Данные». По умолчанию загружены синтетические данные (~370 работающих, ~110 новых за год, около трети ушедших не дорабатывают 90 дней). Реальных людей нет.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173 (порт Vite по умолчанию; если занят — следующий свободный)
npm run build    # проверка типов и статическая сборка в dist/
```

## Стек

Vite, React 19, TypeScript (strict), zustand, CSS Modules. Импорты — через `@/` (это `src/`).

## Структура

```
src/
  main.tsx                 точка входа
  app/App.tsx              композиция: оболочка, вкладки, экраны
  components/
    ui/                    компоненты без домена: Button, Badge, Notice, SegmentedControl, StatCard, ProgressBar
    layout/AppShell/       шапка, навигация, плашка демо-данных
    newcomers/             экран «Мои новички»: NewcomersView, NewcomerCard (карточка, форма и история разговоров)
    hr-summary/            экран «Сводка для HR»
    data-source/           экран «Данные»: импорт выгрузки, пример, сброс
  lib/
    utils/                 чистые функции без доменных импортов: даты, проценты, генератор случайных чисел
    employees/             сотрудник и правила занятости (кто новичок, кто ушёл в первые 90 дней)
    newcomers/             разговоры, контрольные точки, статусы «пора / просрочено / риск»
    hr-summary/            расчёт сводки для HR
    bitrix/                формат задач Битрикс24 и их разбор
    demo/                  выдуманная компания и генератор демо-данных
  store/                   zustand: данные приложения (localStorage) и выбранный руководитель
  styles/                  токены темы и базовые стили
samples/                   маленькая выгрузка с ошибками для проверки импорта
```

Правила:
- компонент — папка `PascalCase/` с `index.ts`; снаружи импортируется только через неё;
- состояние и подготовка данных — в соседнем хуке `useXxx.ts`, в `.tsx` — только разметка;
- части компонента (форма, таблица, подписи) — плоские файлы в его папке;
- `lib/` не знает о компонентах и сторе, `lib/utils/` не импортирует ничего из `@/`;
- файлы: компоненты `PascalCase.tsx`, хуки `useCamelCase.ts`, остальное `kebab-case.ts`, типы и константы — `.types.ts` / `.constants.ts`.
